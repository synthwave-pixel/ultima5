# Ultima III art

These atlases and their manifests are copied from the ultima3 port,
[synthwave-pixel/ultima3](https://github.com/synthwave-pixel/ultima3):
its Standard figures (`figures.*`), its character classes (`classes.*`)
and its painted grounds (`terrain.*`). `npm run tiles` reads them
(`web/tools/art/u3.ts` and `paint.ts`) and draws from them the Modern
look's figures and grounds where Ultima V has the same thing as Ultima
III, so they reach the game through
`web/public/graphics/standard-tiles.png`.

One other sheet comes from the same port, served as it is:
`web/public/graphics/standard-caps.png` (its Standard border's caps).
